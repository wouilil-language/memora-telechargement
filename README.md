# Memora pour Android

**Télécharger :** https://github.com/wouilil-language/memora-telechargement/releases/latest/download/memora.apk

Ce lien donne toujours la version la plus récente.

1. Ouvrez le lien sur votre téléphone Android.
2. Ouvrez le fichier téléchargé.
3. Si Android le demande, autorisez l'installation d'applications inconnues.

Si vous avez déjà Memora, la nouvelle version s'installe par-dessus : vos notes sont conservées.
